DATA USE NOTICE / 2026

隱私與資料使用

本頁說明 MELA 系統需求健檢表單如何使用訪客主動提供的資料。送出表單前，請先確認你同意以下用途。

蒐集資料

表單可能蒐集姓名、公司或品牌名稱、Email、電話、LINE ID、偏好聯絡方式，以及你主動描述的系統需求、預算與時程。

使用目的

  • 判斷適合的網站、系統或 CRM 串接範圍。
  • 透過你選擇的方式聯絡並回覆需求。
  • 改善需求分類、服務流程與報價準確度。

資料流向

表單內容會經由 Google Apps Script 傳送至服務管理者的 Gmail，並以 LINE Messaging API 發送新詢問提醒。Google、LINE 與 GitHub 服務可能依各自政策處理必要的技術資料。

網站使用分析

網站使用 Google Analytics 4 了解頁面瀏覽與不含表單內容的互動，例如開啟需求健檢、完成需求送出等，以改善網站內容與服務流程。Google Analytics 可能使用 Cookie 或類似識別碼，處理頁面瀏覽、瀏覽器與裝置類型等一般技術資料；本網站已關閉 Google Signals 與廣告個人化訊號。不會將表單中的姓名、Email、電話、LINE ID 或需求內容傳送至 Google Analytics。你可查看 Google 隱私權政策，或安裝 Google Analytics 退出瀏覽器外掛 停止 Analytics 蒐集。

Google Consent Mode 與你的選擇

本網站採用 Google Consent Mode 第 2 版的進階同意聲明模式。第一次造訪時，analytics_storage、ad_storage、ad_user_data 與 ad_personalization 都預設為拒絕；本網站的 GA 代碼不會在此狀態寫入新的 Analytics Cookie。進階模式下，Google 代碼仍可能在未同意時傳送不含 Cookie 的評估訊號。若你選擇「允許分析 Cookie」，只會將 analytics_storage 更新為允許，廣告相關儲存與個人化仍維持拒絕。你可以隨時按下方按鈕修改選擇。

保存與分享

資料僅用於需求評估、聯絡與後續合作管理，不會出售給第三方。若合作未成立，管理者應依實際營運需要定期清理不再需要的詢問資料。

請勿填寫的資料

請勿在需求說明中填入密碼、API 金鑰、信用卡、身分證字號、病歷或其他高度敏感資訊。技術憑證會在正式合作後透過另外約定的安全管道處理。
